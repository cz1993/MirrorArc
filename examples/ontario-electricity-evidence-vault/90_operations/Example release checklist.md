# Example release checklist

- [ ] Provenance lists every committed CSV, DOCX, XLSX, PPTX, and PDF.
- [ ] IESO nodes remain metadata-only.
- [ ] Code fixture tests and full MirrorArc tests pass locally.
- [ ] Temporary sync produces all expected original-to-mirror relationships.
- [ ] Template and example lint report no blockers, or documented benign warnings only.
- [ ] DOCX, workbook, slide, PDF, and Catalog Explorer visuals are inspected.
- [ ] No-data scan is clean before any Git publication.
