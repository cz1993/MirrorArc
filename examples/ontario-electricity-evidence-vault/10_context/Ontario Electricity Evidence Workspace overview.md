# Ontario Electricity Evidence Workspace overview

The workspace answers historical Ontario electricity questions from traceable evidence. Public
OGL CSVs are committed as authoritative example sources. Office documents, workbooks, decks, and
PDFs are independently authored or synthetic. IESO pages are represented by metadata-only source
references.

The core path is visible rather than implicit: source artifact -> generated markdown mirror ->
curated finding -> contract, decision, quality check, report, or runbook. [[Evidence lineage map]]
describes the same path for agents.
