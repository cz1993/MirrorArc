# OEB open data directory

Metadata-only reference to the Ontario Energy Board's open-data landing page. It is a candidate
source family for future rate, utility, and market-context extensions. No OEB dataset body is
copied into this example; dataset-level licensing and metadata must be verified before inclusion.
The page was rechecked on 2026-07-21 and identifies annual RRR data, historical XLSX workbooks,
and the Open Government Licence - Ontario; that landing-page statement is not applied blindly to
every linked resource.
