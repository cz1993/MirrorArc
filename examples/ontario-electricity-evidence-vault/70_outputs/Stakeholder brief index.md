# Stakeholder brief index

The output index connects the historical analysis workbooks, public-source register, evidence
controls, and operational review material. Each authored Word or Excel source is mirrored into
Markdown during sync so agents can traverse the same evidence as a person reviewing the original
format.

The stakeholder narrative is historical and methodological; the workspace contains no
forward-looking model output.
