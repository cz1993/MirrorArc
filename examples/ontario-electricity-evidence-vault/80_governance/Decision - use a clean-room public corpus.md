# Decision - use a clean-room public corpus

- **Decision:** build the flagship demo from OGL sources, independently authored artifacts, and
  a small synthetic validation-code fixture.
- **Rejected:** copying any other project's implementation, internal metrics, or IESO source
  bodies.
- **Rationale:** preserves MirrorArc's personal-project boundary, makes the demo redistributable,
  and still exercises a realistic, stakeholder-relevant evidence graph.
- **Consequence:** the example is historical only and contains no company attribution,
  forward-looking output, or organization-specific context.
