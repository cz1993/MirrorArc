# Illustrative model evaluation

The synthetic evaluation workbook contains twelve invented observations and predictions chosen to
produce a 7.7% mean absolute percentage error. The quality threshold is 5.0%. Because 7.7% exceeds
the gate, the result is retained as learning evidence and publication is suppressed.

No row in the workbook is a live forecast or an actual Ontario operational observation.
