# Scenario assumptions

The example's model fixture assumes complete monthly history, unchanged measurement definitions,
and an invented scenario adjustment. These assumptions are intentionally inadequate for a real
forecast. The IESO planning reference is linked for context only and contributes no copied body or
parameter.
