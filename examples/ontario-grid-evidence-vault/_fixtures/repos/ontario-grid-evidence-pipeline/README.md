# Ontario Grid Evidence Pipeline

Clean-room demonstration project for MirrorArc. It loads a small set of Open Government Licence -
Ontario CSV fixtures, normalizes stable analytical tables, evaluates explicit quality gates, and
produces metadata-only publication decisions. It is not the GuildBuild OntarioGrid codebase and
does not publish forecasts or alerts.

Run the fixture tests with `python -m unittest discover -s tests`.
