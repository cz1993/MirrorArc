# IESO reference-only boundary

The public example stores IESO page titles, URLs, source categories, and original MirrorArc
descriptions. It does not commit report bodies, tables, images, or downloaded data from IESO.
Agents must open the current authoritative URL and verify terms before using the material.

An optional private overlay may connect an operator's separately authorized sources, but that
overlay is ignored by Git and is not part of this public example.
